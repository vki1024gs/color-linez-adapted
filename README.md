# Color Linez Adapted

An HTML5 adaptation of Color Lines with retro pixel art and sound effects. **v0.4**, available in English, Simplified Chinese, and Traditional Chinese.

## Play and deploy

Open [index.html](index.html) in a browser, or host it on a static website. No installation required.

## Source and build

Use Node.js 22.13 or newer. Run these commands inside `h5/`:

```sh
npm ci
npm run build
```

Source: `h5/src/`. Build output: `index.html`.
