# Color Linez Adapted

[Play online](https://vki1024gs.github.io/color-linez-adapted/) · [Download](https://github.com/vki1024gs/color-linez-adapted/releases/latest)

Clear the board. Climb the ranks. Claim the crown.

Arrange five or more balls of the same color to clear a line. Match six to sweep the entire row, column, or diagonal; match seven to clear that color from the board. Outscore your rivals and challenge the king in this retro pixel-art puzzle game, playable in your browser or offline.

Available in English, Simplified Chinese, and Traditional Chinese.

## Play and deploy

Open [index.html](index.html) in a browser, or host it on a static website. No installation required.

## Build

Use Node.js 22.13 or newer. Run these commands inside `h5/`:

```sh
npm ci
npm run build
```

The build updates `index.html`.
